# Defensive Security Assessment — Scope

## Objective
Assess my own local Flask authentication application, identify security weaknesses, fix the highest risks, and verify the improvements.

## Authorized Environment
The application running locally on my own computer.

## Scope of Testing
- Application configuration
- Login, registration, and logout
- Password security
- Input validation
- Rate limiting
- Session and cookie security
- Dependencies and security logging

## Out of Scope
External websites, third-party systems, production services, and real user data.

## Rules of Engagement
- Test only my own local application.
- Use test accounts and synthetic data.
- Do not expose passwords, secret keys, or personal information.
- Document findings and retest results.

## Authorization Statement
I authorize security testing of my own local application for this assessment.
